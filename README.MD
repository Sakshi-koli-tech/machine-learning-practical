# Practical No. 15

## Title: Development of an ML Project Using Python and Streamlit

### Aim
To develop and deploy a simple Machine Learning project using Python and Streamlit.

### Software Requirements
- Python
- Visual Studio Code
- Streamlit
- GitHub

### Description
This practical demonstrates the development of a simple web application using Python and Streamlit. The application provides a user-friendly interface where users can enter their name and view a personalized welcome message.

### Tools and Technologies
- Python Programming Language
- Streamlit Framework
- Visual Studio Code
- GitHub

### Execution
1. Created a project folder named ML Project.
2. Created the required Python files.
3. Installed and configured Streamlit.
4. Developed the application using `app.py`.
5. Executed the application using the Streamlit command.
6. Tested the application in a web browser.

### Command Used
```bash
streamlit run app.py
```

### Result
Successfully developed and executed a simple web application using Python and Streamlit.

### Conclusion
Thus, we successfully learned how to develop and run a basic web application using Python and Streamlit.
